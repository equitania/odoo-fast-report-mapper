<objective>
Fix BUG-02 (CR-03): self_clean() destroys calculated-field parameter lists when called in add_calculated_fields(). dict.fromkeys() on a dict iterates over keys only, so {"eq_get_payment_terms": ["p1","p2"]} becomes ["eq_get_payment_terms"]. The fix removes the broken self_clean() call from add_calculated_fields() — outer keys are unique by dict semantics, no deduplication is needed.

Purpose: Reports with calculated fields currently produce silent data corruption at add_calculated_fields() time, causing AttributeError ("list has no attribute 'items'") when set_calculated_fields() later iterates the mangled result.
Output: Fixed _report.py + regression test in test_report.py.
</objective>
