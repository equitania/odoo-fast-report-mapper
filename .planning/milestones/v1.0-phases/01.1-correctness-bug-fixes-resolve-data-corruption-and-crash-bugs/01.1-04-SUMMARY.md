# Phase 01.1 Plan 04: BUG-04 ValueError guard in build_name_search_domain Summary

**One-liner**: Added `if not name_dict: raise ValueError(...)` guard to `build_name_search_domain` to prevent unbounded Odoo search domain that silently overwrites unintended report records.

## What Was Built

Fixed BUG-04 (WR-03): `build_name_search_domain({})` previously returned `[]`, which caused the caller (`map_reports`) to build the domain `[("model", "=ilike", model_name)]` — matching ALL reports for that model and silently updating the first one found. The fix raises `ValueError` immediately on empty input.

### Task 1 — ValueError guard in _lang_utils.py (b7a7714)

Added two-line guard as the first statement in `build_name_search_domain`:

```python
if not name_dict:
    raise ValueError("Cannot build name search domain from empty name_dict")
```

Non-empty inputs are entirely unaffected.

### Task 2 — Updated test to expect ValueError (2b21cdf)

- Renamed `test_empty_dict` → `test_empty_dict_raises_value_error`
- Replaced `assert result == []` with `pytest.raises(ValueError, match="empty name_dict")`
- Added missing `import pytest` to `tests/test_lang_utils.py`
