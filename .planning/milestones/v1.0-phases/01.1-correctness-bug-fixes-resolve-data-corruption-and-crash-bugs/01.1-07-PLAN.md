<objective>
Fix BUG-07 (WR-07): create_odoo_connection_from_yaml_object() hardcodes auth_method='password', so a user who puts an API key in the YAML config has it silently treated as a password (wrong auth behavior). The fix mirrors the existing create_connection_from_env() auth-resolution logic: check api_key first, fall back to password.

Purpose: API key auth via YAML is a supported use case; the silent password treatment causes cryptic authentication failures for API-key-based Odoo instances.
Output: Fixed _utils.py create_odoo_connection_from_yaml_object + TestCreateConnectionFromYamlObject in test_utils.py.
</objective>
