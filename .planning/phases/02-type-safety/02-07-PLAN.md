they tell mypy the expected shape but perform no runtime validation. In the deployment model,
the Odoo server is a trusted peer (authenticated via odoorpc). The `is False` guards for the
Odoo False-sentinel fix add defensive clarity to existing code without changing access control.
No new I/O, no new trust boundary, no new attack surface. No in-scope high-severity threats.
