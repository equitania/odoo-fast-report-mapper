<objective>
Fix BUG-04 (WR-03): build_name_search_domain({}) returns [] when name_dict is empty, which causes the caller to build [("model", "=ilike", model_name)] — matching ALL reports for that model and silently updating the first one found. The fix raises ValueError immediately on empty input.

Purpose: An empty name_dict is never a legitimate state (it would come from a broken YAML); failing loudly prevents data corruption in the target Odoo before any mapping side-effect occurs.
Output: Guarded _lang_utils.py + updated test in TestBuildNameSearchDomain.
</objective>
