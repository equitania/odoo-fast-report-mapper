<objective>
Fix BUG-05 (WR-04): prepare_connection() uses url.replace("https:", "") + while-loop slash stripping, which silently retains path components. A URL like "https://host/web" produces hostname "host/web" which is passed to OdooRPC, causing a silent connection failure. The fix replaces the fragile string manipulation with parsed.hostname from the urlparse result already computed in the function.

Purpose: Any Odoo instance accessed via a URL with a path suffix (e.g., /web, /odoo) fails silently with the current code. This is a common real-world URL shape.
Output: Fixed _utils.py prepare_connection + regression test in TestPrepareConnection.
</objective>
