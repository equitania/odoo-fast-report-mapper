<objective>
Fix BUG-06 (WR-05): Report.__init__ has entry_name annotated as str but always receives a dict at runtime. If Report.self_ensure() were called without the EqReport override, a Python dict would be written to Odoo's name field. The fix adds: (1) annotation dict[str, str], (2) isinstance + non-empty runtime guard raising TypeError on bad input, and (3) atomic update of the two existing string-based fixtures in test_report.py.

Purpose: Fail fast at construction time with a clear TypeError rather than producing a cryptic failure deep in self_ensure(). The fixture updates prevent any other test from being broken by the new guard.
Output: Guarded _report.py + TestReportEntryNameGuard regression tests + updated fixtures in test_report.py.

CRITICAL: This plan shares test_report.py with plan 02 (BUG-02). Plan 06 executes in wave 2, after plan 02 completes. The _make_report helper may already have been updated to dict-shaped entry_name in plan 02 — read the file's current state before writing.
</objective>
